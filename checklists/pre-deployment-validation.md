# Pre-Deployment Validation Checklist

Complete these checks before a workstation is handed to its intended user.

## Device and operating system
- [ ] Device boots and shuts down normally.
- [ ] Windows edition/version is correct for the lab or approved build.
- [ ] Updates are complete or remaining updates are documented.
- [ ] No unexpected Device Manager warnings remain.
- [ ] Storage, battery/power, display, keyboard, and pointing device work.
- [ ] Date/time and regional settings are correct.

## Identity and security
- [ ] Authorized user can sign in and sign out.
- [ ] Access is limited to the required level.
- [ ] Windows Security status has been reviewed.
- [ ] Firewall and security controls remain enabled according to the applicable policy.
- [ ] No test credentials, personal files, or secrets remain.
- [ ] Managed-device enrollment/compliance has been checked only if applicable and authorized.

## Network and applications
- [ ] Network connection works.
- [ ] DNS resolution works for an approved test hostname.
- [ ] VPN works if required and authorized.
- [ ] Required applications open and pass a basic test.
- [ ] Application updates and sign-in are checked where appropriate.
- [ ] Printer, camera, headset, microphone, dock, and external display are tested if required.
- [ ] User data migration is verified only where applicable and authorized.

## Documentation and handover
- [ ] Asset information is recorded in the appropriate private system, if applicable.
- [ ] Installed software and known issues are documented.
- [ ] Open issues have an owner and next step.
- [ ] User knows how to get support and report a problem.
- [ ] Handover is acknowledged where the process requires it.

## Outcome
- Result: `[Pass / Pass with issues / Fail]`
- Outstanding issue(s): `[none or describe]`
- Tester/date: `[name or initials / YYYY-MM-DD]`
- Evidence: `[filename or private record reference; no confidential information]`
