# Software Installation Checklist

## Before installation
- [ ] Confirm the application is required and approved for this device.
- [ ] Check system requirements and Windows compatibility.
- [ ] Obtain the installer from the vendor's official site or approved software portal.
- [ ] Verify publisher/signature when available.
- [ ] Confirm licence or entitlement through the approved process.
- [ ] Check whether administrator approval is required.
- [ ] Close applications and save work before changes.
- [ ] Record current version and relevant settings if an upgrade is planned.

## Install
1. Read the vendor's instructions and release notes.
2. Run the approved installer using the minimum required permissions.
3. Review installation options; avoid optional bundled software.
4. Follow the approved configuration instructions.
5. Record any error message exactly, excluding sensitive details.
6. Restart only if required or directed by the approved procedure.

## Validate
- [ ] Confirm the application appears in Installed apps.
- [ ] Launch it and check for startup errors.
- [ ] Check the version in the application’s About page or approved method.
- [ ] Test a basic, non-sensitive workflow.
- [ ] Verify access using the intended test account.
- [ ] Confirm relevant file types or browser integrations work, if required.
- [ ] Check Event Viewer or application logs if errors occur and access is appropriate.
- [ ] Confirm no unexpected prompts, security warnings, or unwanted bundled software appeared.

## If installation fails
1. Record the full error text and time.
2. Confirm disk space, OS compatibility, network access, and installer source.
3. Check whether another install/update is in progress.
4. Review vendor documentation and relevant logs.
5. Retry only after identifying a reasonable cause; do not repeatedly run an installer blindly.
6. Escalate if administrator rights, licence changes, security exceptions, or managed deployment access are required.
