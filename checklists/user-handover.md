# User Handover Checklist

## Before handover
- [ ] Complete the pre-deployment validation checklist.
- [ ] Confirm the device and accessories are ready.
- [ ] Confirm required applications and approved access.
- [ ] Explain any known limitations or outstanding issues.
- [ ] Remove test accounts and sample data when appropriate.
- [ ] Ensure no passwords or MFA recovery information are written in this document.

## At handover
- [ ] Show the user how to sign in using the approved process.
- [ ] Confirm the user can open the required applications.
- [ ] Confirm connectivity and required peripherals.
- [ ] Explain how to lock the screen and sign out.
- [ ] Explain where to find approved self-service/support resources.
- [ ] Explain how to report an issue and what details to include.
- [ ] Confirm the user understands any next steps.

## After handover
- [ ] Record the handover date and outcome in the appropriate system.
- [ ] Record unresolved incidents separately and assign a follow-up owner.
- [ ] Do not put personal contact details or confidential asset identifiers in this public portfolio.
